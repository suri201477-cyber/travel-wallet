# Мини-кошелёк для путешествия

Telegram-бот ведёт бюджет поездки в двух валютах: домашней и валюте страны назначения. Курс берётся из [exchangerate.host](http://api.exchangerate.host/convert). У каждого пользователя Telegram свои путешествия, они хранятся локально в SQLite.

## Что умеет бот

- Создаёт путешествие: страна отправления, страна назначения, курс и стартовая сумма.
- Хранит несколько поездок и переключается между ними. Активная поездка помечена в списке.
- Показывает баланс всегда в обеих валютах, например `827.85 CNY = 10 000 RUB`.
- Принимает число в чате как расход в валюте назначения и пересчитывает его в домашнюю валюту.
- Спрашивает подтверждение и категорию, прежде чем записать трату.
- Показывает историю расходов и сумму по категориям.
- Позволяет заменить курс на курс местного обменника.

Страна задаётся названием или трёхбуквенным кодом валюты (`Китай`, `CNY`, `Россия`). Валюта страны берётся из локального списка. Если страны нет в списке, бот просит другое название или код валюты.

## Путешествие

1. Бот спрашивает страну отправления и страну назначения.
2. Запрашивает у API, сколько единиц домашней валюты дают за 1 единицу валюты назначения, и показывает курс.
3. Если курс подходит, он сохраняется. Если нет, пользователь вводит свой: `12.8` означает `1 CNY = 12.8 RUB`.
4. Пользователь указывает сумму, которую берёт с собой, в домашней валюте.
5. Эту сумму бот всегда конвертирует через API и создаёт стартовый баланс в обеих валютах. Свой курс при этом остаётся для следующих расходов и уже записанный баланс не пересчитывает.

Одинаковые страна и валюта на въезде и выезде не принимаются. Две страны с одной валютой, например Германия и Франция, можно указать.

## Расходы

В обычном режиме любое число — это трата в валюте страны, где находится пользователь.

1. Бот отвечает строкой вида `100 CNY = 1 207.95 RUB` и спрашивает, учесть ли её как расход.
2. После «Да» предлагает категорию: **Транспорт**, **Жильё**, **Еда**, **Развлечения**.
3. «Нет» или «Не записывать» сумму не сохраняет.
4. После записи бот показывает новый остаток в обеих валютах.

Если для поездки сохранён свой курс, расход считается по нему и API не вызывается. Если курс сервисный, бот запрашивает актуальный курс и обновляет сохранённый. Сумма больше остатка записывается с предупреждением, баланс может стать отрицательным.

В истории видны последние 20 трат с датой и категорией, а сверху — итог по категориям. Записи, сделанные до появления категорий, показаны как «Без категории».

## Меню и команды

Кнопки меню:

- Создать новое путешествие
- Мои путешествия
- Баланс
- История расходов
- Изменить курс

Те же действия доступны командами `/start`, `/newtrip`, `/switch`, `/balance`, `/history`, `/setrate`.

## Запуск

Нужны Python 3.12 и виртуальное окружение проекта. В `.env` две строки:

```
CURRENCY_ACCESS_KEY=ключ_exchangerate_host
TELEGRAM_BOT_TOKEN=токен_от_BotFather
```

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe bot.py
```

Остановить бота: Ctrl+C. Пока бот запущен, он принимает сообщения в Telegram.

## Файлы

| Файл | Назначение |
| --- | --- |
| `bot.py` | Диалоги, меню и команды |
| `current_api.py` | Запросы к exchangerate.host. Бот использует `convert_amount` и адрес `/convert` |
| `countries.py` | Страны и их валюты |
| `storage.py` | Пользователи, поездки и расходы в `wallet.db` |
| `requirements.txt` | `requests`, `python-dotenv`, `pyTelegramBotAPI` |

Ключ и токен читаются только из `.env` и в сообщения бота не попадают. При временном ограничении API повторный запрос уходит после паузы, указанной сервисом.
